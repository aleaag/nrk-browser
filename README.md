# NRK Browser (In development, expect issues)
 
**Browse, watch, listen to and download NRK TV and NRK Radio from one Windows app.**
 
NRK Browser is a single PowerShell script that gives you a fast, folder-based desktop view of
[tv.nrk.no](https://tv.nrk.no) and [radio.nrk.no](https://radio.nrk.no). Watch in NRK's own
player, listen to radio and podcasts in a built-in audio bar, and queue up downloads,
all without a browser tab.

## Features
 
### Browse everything as folders
- **LIVE**: every NRK TV channel (including the regional NRK1 channels) and every NRK Radio
  channel (P1, P2, P3, mP3, Klassisk, Jazz, Nyheter, regional P1 and more), with today's
  programme guide.
- **TV Archive**: all tv.nrk.no categories plus the complete **A–Å** index.
- **Radio Archive**: all radio.nrk.no categories plus the radio **A–Å** index: series, podcasts and
  single programmes.
